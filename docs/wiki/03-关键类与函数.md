## 核心库：`org.bsc.langgraph4j.deepagents`

### 1. [DeepAgent](file:///Users/bytedance/Documents/git_repo/langgraph4j-deepagents/src/main/java/org/bsc/langgraph4j/deepagents/DeepAgent.java)（interface）

#### 1.1 `DeepAgent.State extends AgentExecutor.State`

Deep Agent 的运行时状态容器。

| 成员 | 签名 | 说明 |
| --- | --- | --- |
| `SCHEMA` | `static final Map<String, Channel<?>>` | 在父类 `AgentExecutor.State.SCHEMA` 基础上，用 `mergeMap` 追加 `"files" → new FileChannel()`。定义了状态图中各键的合并规则 |
| `todos()` | `List<ToDo> todos()` | 读取规划清单；缺省返回空 List |
| `files()` | `Map<String,String> files()` | 读取虚拟文件系统；缺省返回空 Map |
| 构造 | `State(Map<String,Object> initData)` | 由序列化器 `DeepAgent.State::new` 调用重建状态 |

> `messages` 等键由父类 `AgentExecutor.State` 提供，这里不再声明。

#### 1.2 `DeepAgent.SubAgent`（record + Builder）

子 Agent 的声明式配置。

```java
record SubAgent(String name, String description, String prompt, List<String> tools)
```

| 字段 | 必填 | 含义 |
| --- | --- | --- |
| `name` | ✅（构造时 `requireNonNull`） | 子 Agent 唯一名，作为 `task` 工具的 `subAgentType` 取值 |
| `description` | ✅（`requireNonNull`） | 给主 Agent 看的「何时使用该子 Agent」说明，会注入 task 工具描述 |
| `prompt` | ❌ | 子 Agent 自己的系统提示词；为 null 时底层 ReactAgent 无默认 system |
| `tools` | ❌ | 该子 Agent 可用的工具名单；为 null 则继承工具池中全部工具 |

- `SubAgent.builder()` 返回链式 `Builder`（`name/description/prompt/tools` → `build()`）。

#### 1.3 `DeepAgent.ToDo`（record）

```java
record ToDo(String content, Status status)
enum Status { PENDING, IN_PROGRESS, COMPLETED }
```

两个字段都标注 `@JsonProperty(required=true)` + `@JsonPropertyDescription`，用于让 LLM 生成结构化的 todo 项。

#### 1.4 `static GraphBuilder builder()`

组装 Deep Agent 的入口，返回新的 [GraphBuilder](file:///Users/bytedance/Documents/git_repo/langgraph4j-deepagents/src/main/java/org/bsc/langgraph4j/deepagents/GraphBuilder.java)。

### 2. [GraphBuilder](file:///Users/bytedance/Documents/git_repo/langgraph4j-deepagents/src/main/java/org/bsc/langgraph4j/deepagents/GraphBuilder.java)（class）

主 Agent 图构建器。链式配置 + 一个 `build()` 产出图。

| 方法 | 签名 | 说明 |
| --- | --- | --- |
| `instructions` | `GraphBuilder instructions(String)` | 主 Agent 的业务系统提示词（可选，为 null 时只用 BASE_PROMPT） |
| `subAgents` | `GraphBuilder subAgents(List<SubAgent>)` | 声明子 Agent（非空时才会创建 `task` 工具）；内部 `List.copyOf` 防御性拷贝 |
| `tools` | `GraphBuilder tools(List<ToolCallback>)` | 业务工具（如 internet_search），进入子 Agent 工具池 |
| `chatModel` | `GraphBuilder chatModel(ChatModel)` | 注入 LLM（`requireNonNull`） |
| `builtinTools` | `GraphBuilder builtinTools(List<String>)` | 内置工具白名单（按工具名过滤 `Tools.BUILTIN`）；不设则用全部 |
| `build` | `StateGraph<DeepAgent.State> build() throws GraphStateException` | 产出可编译的状态图 |

**`build()` 执行步骤**（[L51-L98](file:///Users/bytedance/Documents/git_repo/langgraph4j-deepagents/src/main/java/org/bsc/langgraph4j/deepagents/GraphBuilder.java#L51-L98)）：

1. `tools` 为 null → 置空列表。
2. `selectedBuiltinTools` = 若有 `builtinTools` 白名单则按 `tool.getToolDefinition().name()` 过滤，否则 = `Tools.BUILTIN`。
3. `allTools` = 内置工具的可变副本（注意业务 `tools` **未**直接加入主图，见下方说明）。
4. 若 `subAgents` 非空：构造 `toolsMap`（内置+业务工具，按名索引），传给 `TaskToolBuilder` 生成 `task` 工具并加入 `allTools`。
5. `finalInstructions` = `instructions + Prompts.BASE_PROMPT`（或仅 BASE_PROMPT）。
6. 用 `ReactAgent.builder()` 装配：`SpringAIJacksonStateSerializer`、`chatModel`、`allTools`、`DeepAgent.State.SCHEMA`、`defaultSystem(finalInstructions)` → `build()` 返回 `StateGraph`。

> ⚠️ **易踩坑**：第 3 步中 `allTools.addAll(tools)` 被注释掉（[L66](file:///Users/bytedance/Documents/git_repo/langgraph4j-deepagents/src/main/java/org/bsc/langgraph4j/deepagents/GraphBuilder.java#L65-L66)）。因此业务工具只经由 `task`→子 Agent 工具池被使用，主 Agent 本身不直接持有业务工具。若希望主 Agent 直接调用某业务工具，需要自行放开这行或把该工具纳入内置集。

### 3. [Tools](file:///Users/bytedance/Documents/git_repo/langgraph4j-deepagents/src/main/java/org/bsc/langgraph4j/deepagents/Tools.java)（interface，内置工具工厂）

每个静态方法返回一个 Spring AI `ToolCallback`。参数对象均为内部 record。

#### 3.1 `ls()` → 工具名 `ls`
- 入参：`Void`（无参）。
- 行为：`new DeepAgent.State(context.getContext()).files().keySet()` → 返回所有文件名集合。

#### 3.2 `readFile()` → 工具名 `read_file`
- 入参 `ReadFileArgs(String filePath, int offset=0, int limit=2000)`。
- 行为：文件不存在返回错误串；空文件返回提醒串；否则按 `\n` 切行，从 `offset` 取 `limit` 行，以 `%6d\t%s`（cat -n 风格）输出；单行超 2000 字符截断；非法区间/越界均返回错误串。
- 描述来自 `Prompts.TOOL_DESCRIPTION`。

#### 3.3 `writeFile()` → 工具名 `write_file`
- 入参 `WriteFileArgs(String filePath, String content)`（均必填）。
- 行为：通过 `SpringAIToolResponseBuilder.update(Map.of("files", Map.of(filePath, content)))` 写入状态，返回 `"Updated file ..."`。依赖 FileChannel 合并语义累积文件。

#### 3.4 `editFile()` → 工具名 `edit_file`
- 入参 `EditFileArgs(String filePath, String oldString, String newString, boolean replaceAll)`。
- 行为：
  - 文件不存在 / `oldString` 不在文件中 → 返回错误串。
  - 非 `replaceAll` 模式下，若 `oldString` 出现多次 → 返回「出现 N 次，请用 replace_all 或提供更具上下文的字符串」错误；出现 0 次 → 错误。
  - 用 `Pattern.quote` 转义后，`replaceAll ? content.replaceAll(...) : content.replaceFirst(...)` 得到新内容并写回状态。
- 描述来自 `Prompts.EDIT_DESCRIPTION`。

#### 3.5 `writeTodos()` → 工具名 `write_todos`
- 入参 `writeTodosArgs(List<ToDo> toDos)`（必填）。
- 行为：`SpringAIToolResponseBuilder.update(Map.of("todos", input.toDos()))`，返回 `"Updated todo list to <json>"`。
- 描述来自 `Prompts.WRITE_TODOS_DESCRIPTION`；inputSchema 由 `JsonSchemaGenerator` 生成。

#### 3.6 `BUILTIN`
```java
List<ToolCallback> BUILTIN = List.of(ls(), readFile(), writeFile(), editFile(), writeTodos());
```
内置工具清单，供 `GraphBuilder` / `TaskToolBuilder` 消费。

### 4. [TaskToolBuilder](file:///Users/bytedance/Documents/git_repo/langgraph4j-deepagents/src/main/java/org/bsc/langgraph4j/deepagents/TaskToolBuilder.java)（class）

构建 `task` 工具（子 Agent 调度器）。

| 方法 | 签名 | 说明 |
| --- | --- | --- |
| `subAgents` | `TaskToolBuilder subAgents(List<SubAgent>)` | 要调度的子 Agent 列表 |
| `tools` | `TaskToolBuilder tools(Map<String,ToolCallback>)` | 可供子 Agent 解析的工具池（名→工具） |
| `model` | `TaskToolBuilder model(ChatModel)` | 子 Agent 使用的 LLM |
| `build` | `ToolCallback build() throws GraphStateException` | 产出名为 `task` 的工具 |

内部 record：`TaskToolArgs(String description, String subAgentType)`，两字段均 `requireNonNull`。

**`build()` 要点**（[L59-L167](file:///Users/bytedance/Documents/git_repo/langgraph4j-deepagents/src/main/java/org/bsc/langgraph4j/deepagents/TaskToolBuilder.java#L59-L167)）：

1. **构建 `agentsMap`**：对每个 `SubAgent`——
   - 若声明了 `tools` 名单，从工具池逐个解析（解析不到则 `log.warn`）；未声明则取工具池全部。
   - 用 `ReactAgent.builder()`（带 `SpringAIJacksonStateSerializer`、`State.SCHEMA`、`defaultSystem(subAgent.prompt())`）构建一个子 Agent 的 `StateGraph`，存入 `agentsMap[name]`。
2. **task 工具的执行函数**：
   - 按 `subAgentType` 取子 Agent；取不到返回「可用 Agent 列表」错误串。
   - 用 `mergeMap(当前上下文, {messages: UserMessage(description)}, 取新值)` 构造输入状态。
   - `reactAgent.compile().invokeFinal(GraphInput.args(inputState), config)` 执行子 Agent。
   - 把输出状态的 `files` 合并回主状态（`SpringAIToolResponseBuilder.update`），返回子 Agent 最后一条消息文本（无则 "Task completed"）。
   - 异常被捕获并转为错误串返回（不抛出）。
3. **工具元信息**：inputSchema 用内联 JSON（动态填入可用子 Agent 名）；description 由 `TASK_DESCRIPTION_PREFIX`（替换 `{other_agents}` 为「- name: description」列表）+ `TASK_DESCRIPTION_SUFFIX` 拼成。

> 每次 `task` 调用都 `reactAgent.compile()` 一次（图结构已预建，编译为可执行实例），子 Agent 调用是**无状态**的（除了回写 files）。

### 5. [FileChannel](file:///Users/bytedance/Documents/git_repo/langgraph4j-deepagents/src/main/java/org/bsc/langgraph4j/deepagents/FileChannel.java)（class）

实现 `Channel<Map<String,String>>`，定义 `files` 键的状态合并规则。

| 方法 | 说明 |
| --- | --- |
| `getReducer()` | 返回 `reduce` 方法作为 Reducer |
| `getDefault()` | 返回 `Map::of`（空 Map 作为初值） |
| `reduce(map1, map2)`（private） | `mergeMap(map1, map2, (v1,v2) -> v2)`：增量合并，**同名键用新值覆盖** |

这是「文件累积、同名覆盖」行为的唯一来源。[ToolsTest.testFileChannel](file:///Users/bytedance/Documents/git_repo/langgraph4j-deepagents/src/test/java/org/bsc/langgraph4j/deepagents/ToolsTest.java#L33-L54) 专门验证了该合并语义。

### 6. [Prompts](file:///Users/bytedance/Documents/git_repo/langgraph4j-deepagents/src/main/java/org/bsc/langgraph4j/deepagents/Prompts.java)（interface）

纯常量集合，详见 [02 章 A6](./02-核心模块职责.md)。使用方：

- `BASE_PROMPT` → `GraphBuilder` 拼接。
- `WRITE_TODOS_DESCRIPTION` / `TOOL_DESCRIPTION` / `EDIT_DESCRIPTION` → `Tools` 各工具描述。
- `TASK_DESCRIPTION_PREFIX` / `TASK_DESCRIPTION_SUFFIX` → `TaskToolBuilder` 的 task 工具描述。

## 适配 / 示例层关键 API

### 7. [AiModel](file:///Users/bytedance/Documents/git_repo/langgraph4j-deepagents/src/test/java/org/bsc/langgraph4j/deepagents/AiModel.java)（enum）

4 个枚举值封装了各 LLM 的 `ChatModel` 构建：`OPENAI`、`OLLAMA`（本地 `http://localhost:11434`）、`GITHUB_MODEL`（`https://models.github.ai/inference`）、`GEMINI`（Vertex AI）。

- `chatModel(String model)` / `chatModel(String model, Map<String,String> extraAttributes)`：按模型名构建 `ChatModel`。
- `extraAttribute(...)`：按 key 从「显式传入 Map → 系统属性 → 环境变量」顺序取值（取不到则抛异常）。典型 key：`OPENAI_API_KEY`、`GITHUB_MODELS_TOKEN`、`GOOGLE_CLOUD_PROJECT`、`GOOGLE_CLOUD_LOCATION`。

### 8. [AiTools](file:///Users/bytedance/Documents/git_repo/langgraph4j-deepagents/src/test/java/org/bsc/langgraph4j/deepagents/AiTools.java)（interface）

- `TavilyApi tavilyApiClient()`：需实现方提供搜索客户端。
- `default ToolCallback internetSearch()`：构建名为 `internet_search` 的工具；入参 `InternetSearchArg(query, maxResult=5, topic=general, includeRawContent=false)`；返回 `List<TavilyApi.Response.Result>`。

### 9. [TavilyApi](file:///Users/bytedance/Documents/git_repo/langgraph4j-deepagents/src/test/java/org/bsc/langgraph4j/deepagents/TavilyApi.java)（interface）

- `Response search(Request request)`：唯一方法。
- `Request` / `Response` 为 record（含 Builder 与 Jackson 注解），`ImageDeserializer` 兼容 images 字段既可能是字符串数组也可能是对象数组。
- 两种实现：[TavilyApiHttpClient](file:///Users/bytedance/Documents/git_repo/langgraph4j-deepagents/src/test/java/org/bsc/langgraph4j/deepagents/TavilyApiHttpClient.java)（JDK HttpClient）与 [TavilyApiRestClient](file:///Users/bytedance/Documents/git_repo/langgraph4j-deepagents/src/test/java/org/bsc/langgraph4j/deepagents/TavilyApiRestClient.java)（Spring RestClient，`@Component`）。都会填默认值并向 `https://api.tavily.com/search` 发 POST，Authorization 用 `Bearer <key>`。

### 10. [AiPrompt](file:///Users/bytedance/Documents/git_repo/langgraph4j-deepagents/src/test/java/org/bsc/langgraph4j/deepagents/AiPrompt.java)（enum）

示例业务提示词：`MAIN_AGENT`（主研究员，含报告写作规范与引用规则）、`RESEARCH_AGENT`（研究子 Agent）、`CRITIQUE_AGENT`（评审子 Agent）。`value()` 取文本。

### 11. 运行入口关键方法

- [DeepagentsConsoleController](file:///Users/bytedance/Documents/git_repo/langgraph4j-deepagents/src/test/java/org/bsc/langgraph4j/deepagents/DeepagentsConsoleController.java)：
  - `runDeepagents(console)`：无子 Agent，纯 ReAct + internet_search。
  - `runDeepagentsWithSubAgent(console)`：单个研究子 Agent。
  - `runDeepagentsWithSubAgents(console)`：研究 + 评审双子 Agent（默认启用，`run()` 里调用），执行后打印 todos / files / 最终结果。
- [JtDeepAgentsApp](file:///Users/bytedance/Documents/git_repo/langgraph4j-deepagents/src/test/java/JtDeepAgentsApp.java)：
  - `buildAgent(chatModel, tools)`：等价组装（研究 + 评审双子 Agent）。
  - `executeAgent(agent, userMessage)`：`agent.stream(...)` 流式执行，把每个节点/增量 chunk 渲染到 Javelit UI。
