## 0. 前置条件

| 项 | 要求 |
| --- | --- |
| JDK | **17+**（使用 Javelit UI 需 **21+**，`javelit` profile 才会激活） |
| 构建工具 | Maven（仓库未自带 `mvnw`，用本机 `mvn`） |
| LLM | 至少一个可用的 LLM（OpenAI / Ollama / Gemini / GitHub Models） |
| Tavily | 示例的 Web 搜索需要 `TAVILY_API_KEY` |

### 环境变量

按所选模型/工具设置（`AiModel` 的取值顺序为：显式传入 → 系统属性 → 环境变量）：

```bash
export OPENAI_API_KEY=sk-xxxx          # OpenAI / 默认
export TAVILY_API_KEY=tvly-xxxx        # Tavily 搜索（示例必需）
# 其他可选：
export GITHUB_MODELS_TOKEN=ghp_xxxx    # GitHub Models
export GOOGLE_CLOUD_PROJECT=my-proj    # Gemini
export GOOGLE_CLOUD_LOCATION=us-central1
```

## 1. 方式一：Spring Boot CLI（控制台演示，默认推荐）

入口：[DeepagentsDemoApplication](file:///Users/bytedance/Documents/git_repo/langgraph4j-deepagents/src/test/java/org/bsc/langgraph4j/deepagents/DeepagentsDemoApplication.java) → [DeepagentsConsoleController](file:///Users/bytedance/Documents/git_repo/langgraph4j-deepagents/src/test/java/org/bsc/langgraph4j/deepagents/DeepagentsConsoleController.java)（`CommandLineRunner`）。

### 1.1 选择模型 profile

配置文件 [application.yaml](file:///Users/bytedance/Documents/git_repo/langgraph4j-deepagents/src/test/resources/application.yaml) 决定启用哪个模型与应用形态：

```yaml
spring:
  profiles:
    active: openai        # 可切换为 ollama / gemini / github-models
  main:
    web-application-type: none   # 控制台应用；改成 servlet 可启用 Studio
```

profile 与 `ChatModel` Bean 的对应（见 [ChatModelConfiguration](file:///Users/bytedance/Documents/git_repo/langgraph4j-deepagents/src/test/java/org/bsc/langgraph4j/deepagents/ChatModelConfiguration.java)）：

| profile | 模型 | 备注 |
| --- | --- | --- |
| `openai` | `gpt-4o-mini` | 默认 |
| `ollama` | `qwen3:8b` | 需本地 Ollama 运行中 |
| `gemini` | `gemini-2.5-pro` | 需 Vertex AI 配置 |
| `github-models` | `gpt-4o-mini` | 需 `GITHUB_MODELS_TOKEN` |

### 1.2 运行

因为入口类与配置都在 `src/test`，常见方式是以测试作用域运行 Spring Boot，例如：

```bash
# 方式 A：用 Maven 执行（test classpath）
mvn -q -Dspring-boot.run.main-class=org.bsc.langgraph4j.deepagents.DeepagentsDemoApplication \
    -Dspring-boot.run.profiles=openai spring-boot:run

# 方式 B：在 IDE 中直接运行 DeepagentsDemoApplication（选择 openai profile）
```

> 运行后 `DeepagentsConsoleController.run()` 默认调用 [runDeepagentsWithSubAgents](file:///Users/bytedance/Documents/git_repo/langgraph4j-deepagents/src/test/java/org/bsc/langgraph4j/deepagents/DeepagentsConsoleController.java#L52-L132)，对内置示例问题「对 LangGraph4j 项目做深度研究」跑一轮「研究 + 评审」流程，并在控制台打印 **TODO 清单 / 生成的文件（question.txt、final_report.md）/ 最终报告**。
>
> 想切换到「无子 Agent」或「单子 Agent」演示，可在 [run()](file:///Users/bytedance/Documents/git_repo/langgraph4j-deepagents/src/test/java/org/bsc/langgraph4j/deepagents/DeepagentsConsoleController.java#L39-L50) 里改调 `runDeepagents` / `runDeepagentsWithSubAgent`。

## 4. 以库的形式集成到你自己的项目

若你只想用核心能力（`src/main`），把本项目作为依赖，然后用 Builder 组装：

```java
// 1) 声明子 Agent
var research = DeepAgent.SubAgent.builder()
        .name("research-agent")
        .description("用于深入研究单一主题，一次只给一个问题")
        .prompt("你是一名专职研究员……")
        .tools(List.of("internet_search"))   // 引用工具池中的工具名
        .build();

// 2) 组装主 Agent（会自动拼接 Prompts.BASE_PROMPT）
var agent = DeepAgent.builder()
        .instructions("你是资深研究员，先把问题写入 question.txt，再调研，最后写 final_report.md")
        .subAgents(List.of(research))
        .chatModel(myChatModel)              // 自带 Spring AI ChatModel
        .tools(List.of(myInternetSearchTool))// 自带业务工具（ToolCallback）
        .build()
        .compile(CompileConfig.builder().recursionLimit(100).build());

// 3) 执行
var input = Map.<String,Object>of("messages", new UserMessage("对 X 做深度研究"));
var output = agent.stream(input, RunnableConfig.builder().build())
        .stream().reduce((a, b) -> b).orElseThrow();

// 4) 取结果
output.state().todos().forEach(System.out::println);          // 规划清单
output.state().files().forEach((k, v) -> System.out.println(k)); // 产出文件
System.out.println(output.state().lastMessage());              // 最终答复
```

### 自定义要点

| 想改什么 | 改哪里 |
| --- | --- |
| Agent 行为/领域 | 主 `instructions` 与子 Agent `prompt`；或内置 [Prompts.java](file:///Users/bytedance/Documents/git_repo/langgraph4j-deepagents/src/main/java/org/bsc/langgraph4j/deepagents/Prompts.java) |
| 换 LLM | 传入任意 Spring AI `ChatModel`（参考 [AiModel](file:///Users/bytedance/Documents/git_repo/langgraph4j-deepagents/src/test/java/org/bsc/langgraph4j/deepagents/AiModel.java)） |
| 换记忆存储 | 当前为内存虚拟文件系统（[FileChannel](file:///Users/bytedance/Documents/git_repo/langgraph4j-deepagents/src/main/java/org/bsc/langgraph4j/deepagents/FileChannel.java)）；可替换为自定义 Channel 接 DB/向量库 |
| 加业务工具 | 实现 Spring AI `ToolCallback`，通过 `.tools(...)` 注入（注意主图默认只经 task→子 Agent 使用，见 [04 章](./04-依赖关系.md) 及 GraphBuilder 的注释行说明） |
| 限制内置工具 | `GraphBuilder.builtinTools(List<String>)` 白名单过滤 |

## 5. 常见注意事项

1. **递归限制**：复杂研究任务容易触发 ReAct 循环上限，示例用 `recursionLimit(100)`。任务更深时需调大。
2. **业务工具的可见性**：主 Agent 默认不直接持有业务工具（`GraphBuilder` 里 `allTools.addAll(tools)` 被注释）。要让主 Agent 直接用某工具，需自行放开或并入内置集。详见 [03 章 GraphBuilder 的易踩坑说明](./03-关键类与函数.md)。
3. **HITL 未实现**：README 明确当前不支持人机协同中断点。
4. **示例代码位于 `src/test`**：运行入口、模型装配、Tavily 客户端都在测试作用域，集成到生产时需要把等价逻辑搬到 `src/main` 或自己的工程里。
