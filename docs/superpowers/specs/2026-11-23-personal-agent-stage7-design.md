# 第七课设计

用户已同意继续既有课时路线，并要求接入新增 Web 工作台。本课交付 A/B 和长任务的暂停、重启恢复与持久运行记录。

## 状态设计

复用检查点中的完整消息历史作为恢复依据。研究工具从已保存的成功读取结果重建行范围，长任务从成功计划更新和原始工具结果重建计划及产物索引。恢复过程不执行历史工具，也不调用模型。产物编号按原历史顺序重建，原文可从检查点重新归档，归档目录可改变。

检查点绑定研究模式、模型、目录、字符预算、产物目录、输出路径与输入内容指纹。研究指纹使用现有白名单扫描，要求完整扫描且总输入不超过 4 MiB。超限明确拒绝创建可恢复任务。恢复和发布前检查指纹，变化后停止，避免旧行号与新内容混用。既有第六课检查点保持兼容。

笔记发布在检查点 COMPLETED 后执行。恢复时允许验证并复用内容完全一致的既有输出，冲突内容继续拒绝，处理发布后进程退出的窗口。

Web 每次启动任务和结束任务时原子保存运行配置、结果、事件及消息。重启读取记录，安全批次可手动恢复，工具执行中断的任务显示待核对。凭据仅从 .env 读取。运行目录使用独占进程锁。最近二十条记录展示，暂停记录不能因历史淘汰失去恢复入口。

## 页面和教学

源码、笔记与长任务提供批次后暂停选项，详情增加恢复状态标签页，展示检查点阶段、输入版本和当前计划。已有表单、轨迹、下载入口沿用。为方便观察，A/B 回放在第三批读取证据后暂停，长任务在第二批归档后暂停。

## 验收

离线测试覆盖 A/B 恢复后的引用、内容变更拒绝、相同输出复用与冲突保护、计划和产物读回、旧检查点兼容。实际启动新 Web 服务，浏览器创建暂停任务，重启服务后恢复并下载笔记。Web 服务绑定本地地址，示例运行使用 replay。
