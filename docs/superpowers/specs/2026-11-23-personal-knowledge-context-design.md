# 个人知识库作为 Agent 上下文

用户已选择先在本地检索和预览，每次在 Web 选择资料后才启动 DeepSeek。

## 范围与架构

`PERSONAL_KNOWLEDGE_ROOT` 在本机 `.env` 配置。用户补充只看最近一年，默认滚动一年（本次为 2025-11-23 至 2026-11-23）。日期优先使用笔记更新/创建元数据，其次文件名或目录日期。只有新修改时间但缺少明确日期的文件不进入默认索引，并统计为日期待确认。旧资料正文不进入上下文。只读取 Markdown，跳过隐藏路径、符号链接、Harness、SKILL sync、outputs、构建与凭据目录。PDF、图片、表格本轮不解析。原始目录不写入任何文件。

纯 JDK 的 KnowledgeBase 在内存中建立文件、标题、带原始行号的片段索引。中英文词项匹配、标题和路径权重用于排序，公开命中依据，不声称语义检索。刷新重建索引并记录跳过原因；无命中时不创建模型任务。

Web 个人知识库页面提供状态、手动刷新、检索、原文预览、逐篇选择。每次最多选择六篇且总大小不超过 2 MiB；页面明确选中文件全文对本次模型可读。提交时校验索引版本和文件内容，变化时要求重新预览。选择资料后在本机 Application Support 下创建不可变资料快照，保留相对路径与行号，复用已有 notes 工具、引用校验与检查点。检索默认不调用任何模型。

专用接口拒绝未确认的 DeepSeek 启动，通用运行入口不接受绕过选择步骤的 knowledge 场景。执行轨迹记录检索、选中和快照阶段，模型输入中保留命中行号与资料来源。运行期间只提供快照中的资料，未选文件不在工具范围。

## 数据与边界

原文和索引不提交到 Git。索引只在内存；本地 `.env` 忽略；选中资料快照在 `~/Library/Application Support/PersonalJavaAgent/knowledge/runs/`，运行消息与输出延续现有被忽略的 `out/web/`。目录中的文章仅为证据，不作为执行指令。不自动建立全库关注，不自动发送笔记给模型。

## 验收

三组核心检查：本地检索与过滤、选中文件快照/版本变化拒绝、Web 检索→选择→回放→引用产出。最后用用户真实目录验证索引和中文检索，真实笔记不用于自动 DeepSeek 联调。提供第十三课的调试步骤。
