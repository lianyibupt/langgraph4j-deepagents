# 第8课：持续关注与事件触发

在「主动服务」选择 Markdown 或源码目录，填写研究目标、关键词、检测间隔与每日预算。建立关注时保存基线，后续新增、修改和删除资料才产生事件。

## 运行实验

先用观察模式建立关注，修改一份资料，点击「立即检查」。在事件中检查变化文件、规则判断和输入快照，再批准本次研究。切换自动模式时，请建立新的关注项并选择自动进行只读研究。

```sh
bash personal-agent/web.sh
```

访问 http://127.0.0.1:8080。调试时先停止普通服务，再运行下列命令，使用 Trae 现有的 Attach localhost:5005 配置连接。

```sh
bash personal-agent/web.sh --debug
```

## 断点

SourceWorkspace.snapshot 的 DEBUG S8-1 与 ProactiveAgent.scan 的 DEBUG S8-2。

## 实现边界

程序按关键词检测相关变化，模型执行研究。资料快照固定版本，避免任务执行时输入继续变化。检测仅在 Web 服务运行时进行，白名单、4 MiB 总内容与单文件限制沿用第七课。

## 核心验证

本轮通过实际 HTTP 接口验证自动触发与去重、观察后批准、问答与停止、恢复投递、目标召回与建议。核心运行时另外验证最终回答期间到达的输入和批次内停止。
