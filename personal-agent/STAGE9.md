# 第9课：执行中纠正、问答和停止

运行详情新增「协作输入」。运行中可以追加要求，任务在安全边界将其加入原始消息和下一轮模型输入。输入记录分别展示接收与应用状态。

## 运行实验

选择知识整理，展开高级参数，勾选「先询问研究方向，再等待我的回答」。运行到等待回答后，打开协作输入填写重点。任务会继续，在模型输入中找到对应的追加要求。另建一项问答任务，等待时点击停止。

```sh
bash personal-agent/web.sh
```

访问 http://127.0.0.1:8080。调试时先停止普通服务，再运行下列命令，使用 Trae 现有的 Attach localhost:5005 配置连接。

```sh
bash personal-agent/web.sh --debug
```

## 断点

AgentRuntime.applyInputs 的 DEBUG S9-1，以及 AgentRuns.control、input、action。

## 实现边界

停止采用协作方式，模型请求和正在执行的工具先完成安全收尾。未开始的工具会收到取消结果，保持调用与结果成对。等待回答不占用模型执行槽位。恢复时使用稳定输入 ID 防止重复应用。

## 核心验证

本轮通过实际 HTTP 接口验证自动触发与去重、观察后批准、问答与停止、恢复投递、目标召回与建议。核心运行时另外验证最终回答期间到达的输入和批次内停止。
