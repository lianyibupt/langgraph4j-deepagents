# 第十三课：近期个人知识如何成为 Agent 上下文

本课将个人 Markdown 目录接成可检索的资料源。每次任务依次经过本地检索、预览选择、固定资料版本、模型按需读取、引用校验和另存产出。搜索与预览不调用模型，只有点击 DeepSeek 整理才授权本次选中文件对模型可读。

## 最近一年

默认采用上海时区当前日期向前一年。本次接入为 2025-11-23 至 2026-11-23。

日期首先取笔记前部的更新、创建或日期字段，其次取文件名或目录日期。只有年份时按当年年初保守筛选，页面会标明“路径年份”。这只是文档组织日期的依据，不能证明实际创作时间。日期晚于今天、早于窗口或无法确认的文件不入库。

这批导入资料的修改时间全部较新，因此没有用修改时间替代内容日期。初次实际检查纳入 65 篇资料、837 个片段，167 篇缺少明确日期而排除；数量会随资料变化。缺少日期的 AI 思考笔记也可能被排除，当前索引不能代表全部近期 AI 协作产物。

只读取 `.md` 与 `.markdown`。隐藏目录、符号链接、Harness、SKILL sync、outputs、凭据与构建目录均被排除。PDF、图片和表格尚不提取正文。单文件上限 512 KiB，索引总正文上限 16 MiB，扫描上限 20000 项，达到限制会报告计数。

## 配置与体验

在本机 `personal-agent/.env` 配置下列路径。本机已配置为用户指定的个人目录，`.env` 已被 Git 忽略。

```dotenv
PERSONAL_KNOWLEDGE_ROOT=/Users/bytedance/Documents/personal
```

从仓库根目录启动，打开 http://127.0.0.1:8080/#knowledge。

```sh
bash personal-agent/web.sh
```

1. 点击“AI 协作产物”进行本地检索，也可以输入“Agent 架构 思考”或限制 `research` 目录。
2. 核对命中词、原文路径、行号、日期依据，点击“预览全文与行号”。
3. 明确选择最多六篇资料，总全文不超过 2 MiB。Agent 可读取的是这些选中文件的全文。
4. 先点击“用回放观察执行过程”学习工具调用，或由你点击“将选中资料交给 DeepSeek 整理”进行真实分析。
5. 任务跳转到运行控制台。“执行轨迹”开头有检索、选中和快照事件；“模型输入”可查看来源提示与工具结果怎样逐轮进入上下文。

预览使用索引版本。资料在预览后变化时，启动任务会要求刷新索引并重新选择，避免把未确认的新内容交给模型。索引手动刷新，不在后台持续扫描整个个人目录。

默认整理问题面向近期 AI 协作产物，包含已有产出、关键认识变化、可复用方法、未解决问题与下一步建议。回答必须保留实际读取行的引用，并明确只覆盖所选资料。可以按主题分多次整理，不能将一次六篇的结果称为全年全量总结。

## 数据在哪里

- 原始个人目录保持只读。
- 全文索引只在本机内存，重启后按需重建。
- 选中文件的固定快照在 `~/Library/Application Support/PersonalJavaAgent/knowledge/runs/<run-id>/notes/`，相对路径、正文和行号保持不变。相邻 `context.json` 记录本次来源、哈希、检索与是否明确启动外部模型。任务目录权限为当前用户独占。
- 检查点、实际模型消息和生成结果沿用被忽略的 `personal-agent/out/web/`。这些运行记录会包含已经选中的个人资料，应保存在本机。
- 工具只绑定本次快照目录，无法通过本次知识研究工具读取未选文件。知识库文件中的操作指令只视作资料。

## Trae 调试

先停止普通 Web 服务，再运行下列命令，以已有 Attach localhost:5005 配置连接。继续 JVM 后再在 Web 操作。

```sh
bash personal-agent/web.sh --debug
```

| 断点 | 观察内容 |
| --- | --- |
| `KnowledgeBase.refresh` 的 `DEBUG K1` | 哪些近期文件进入索引，哪些因日期或范围被排除 |
| `KnowledgeBase.search` 的 `DEBUG K2` | 词项、候选片段、排序分、原文路径行号 |
| `KnowledgeBase.snapshot` 的 `DEBUG K3` | 选中文件、内容哈希和快照目录 |
| `KnowledgeService.start` 的 `DEBUG K4` | 明确选择怎样形成研究目录与来源提示 |
| `AgentRuntime.runLoop` 的模型调用前 | 首轮来源提示、后续 read_note 结果与最终消息列表 |

## 核心验证

```sh
bash personal-agent/test.sh --http
```

`KnowledgeBaseTest` 使用合成笔记，检查中文检索、旧笔记/日期不明笔记排除、选中范围、实际工具与引用校验、原文变化后拒绝旧选择。Web 的 `smoke-knowledge.py` 必须连接独立的合成资料服务，脚本会拒绝对真实个人知识库进行修改测试。

这次真实目录只验证本地索引、检索和页面选择，没有自动发送个人笔记到 DeepSeek。
