# 第10课：Outbox 与站内通知

「通知中心」展示结果、待回答问题、投递状态、失败信息和已读回执。消息投递与研究执行分别保存。

## 运行实验

先暂停投递，再运行一项研究。研究完成后检查待投递消息，恢复投递，观察同一条消息变为已送达，并确认模型轮次没有增加。点击标为已读。

```sh
bash personal-agent/web.sh
```

访问 http://127.0.0.1:8080。调试时先停止普通服务，再运行下列命令，使用 Trae 现有的 Attach localhost:5005 配置连接。

```sh
bash personal-agent/web.sh --debug
```

## 断点

ProactiveAgent.deliver 的 DEBUG S10-1。

## 实现边界

本课交付渠道为站内通知，完整消息以稳定 ID 发布到 out/web/notifications。重试核对同一文件内容，避免同一消息重复发布。失败按退避重试，五次后允许手动重试。已送达与已读分别记录。

## 核心验证

本轮通过实际 HTTP 接口验证自动触发与去重、观察后批准、问答与停止、恢复投递、目标召回与建议。核心运行时另外验证最终回答期间到达的输入和批次内停止。
