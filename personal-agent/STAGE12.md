# 第12课：长期目标、偏好召回与主动建议

在「长期目标」保存目标、偏好、关键词、目录和生效范围。相同目录的研究命中关键词时，目标进入本次模型上下文，并保留目标 ID。

## 运行实验

保存一项观察模式目标，再用同一目录提交包含关键词的研究。打开模型输入查看本次采用的目标，随后查看持续服务建议。批准建议会建立关注，拒绝建议会记录拒绝。停用目标会暂停由该目标建立的关注项。

```sh
bash personal-agent/web.sh
```

访问 http://127.0.0.1:8080。调试时先停止普通服务，再运行下列命令，使用 Trae 现有的 Attach localhost:5005 配置连接。

```sh
bash personal-agent/web.sh --debug
```

## 断点

ProactiveAgent.startManual、acceptSuggestion、goalEnabled。

## 实现边界

当前召回和建议依据是精确目录范围与关键词规则，可以直接核对。自动模式明确允许在所选目录建立只读关注。研究本身支持 DeepSeek，协议回放仅展示确定的工具过程。已有任务保留启动时复制的目标内容。

## 核心验证

本轮通过实际 HTTP 接口验证自动触发与去重、观察后批准、问答与停止、恢复投递、目标召回与建议。核心运行时另外验证最终回答期间到达的输入和批次内停止。
