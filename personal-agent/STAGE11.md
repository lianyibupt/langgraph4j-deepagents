# 第11课：监督多个任务与查看执行过程

运行控制台展示正在推进、等待回答、暂停和待核对的任务。每个运行有阶段提示、轨迹、完整消息、实际模型输入、协作输入和恢复状态。

## 运行实验

让一个任务进入等待回答，再提交另一项研究，确认第二项继续完成。通过主动服务中的事件打开执行过程，对照输入版本、工具参数、原始结果与最终引用。

```sh
bash personal-agent/web.sh
```

访问 http://127.0.0.1:8080。调试时先停止普通服务，再运行下列命令，使用 Trae 现有的 Attach localhost:5005 配置连接。

```sh
bash personal-agent/web.sh --debug
```

## 断点

AgentRuns.control.observe、AgentRuntime.runLoop、ProactiveAgent.tick。

## 实现边界

最多两个任务并行请求模型或执行工具。执行阶段描述模型请求和工具调用等可观察动作。最近四百条轨迹滚动保留，完整消息仍在运行记录及检查点中。最近二十条记录保留，运行中、等待回答和暂停记录受到淘汰保护。

## 核心验证

本轮通过实际 HTTP 接口验证自动触发与去重、观察后批准、问答与停止、恢复投递、目标召回与建议。核心运行时另外验证最终回答期间到达的输入和批次内停止。
